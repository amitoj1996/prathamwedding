## How to Use

### Option 1: Open in Browser
Simply open `index.html` in any modern web browser.

### Option 2: Serve with Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 3: Host on Server
Upload both `index.html` and `styles.css` to your web server and access the invitation via URL.

## Customization

To customize the invitation:

1. **Update event details** - Edit the event dates, times, and descriptions in `index.html`
2. **Change colors** - Modify the color values in `styles.css`
3. **Update names** - Replace groom and bride names in the HTML
4. **Add venue details** - Update the venue section with additional information

## Domain Setup

To set this up on a custom domain:
1. Upload the files to your web hosting
2. Configure DNS records to point to your hosting provider
3. Access via your custom domain (e.g., `prathamandpriyanka.com`)
